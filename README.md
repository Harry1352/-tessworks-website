# TessWorks website starter

A responsive starter site using plain HTML, CSS and JavaScript. No paid builder or build tools required.

## Preview
Unzip the folder and double-click `index.html` to open it in your browser.

## Publish with GitHub Pages
1. Create a **public** GitHub repository named `tessworks-website`.
2. Upload `index.html`, `style.css`, and `script.js` into the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Choose branch `main`, folder `/ (root)`, then Save.
6. GitHub will show your free Pages address.

## Connect tessworks.in
After Pages is working, enter `tessworks.in` in Settings → Pages → Custom domain. Then follow the exact DNS records shown in GitHub's instructions and add them in GoDaddy DNS. Do not guess DNS values. Enable HTTPS when available.

Before public launch, replace `hello@tessworks.in` with a working email and add real screenshots, approved founder photo and project links. The film is currently a placeholder. Proposed divisions and early research are labelled accordingly.

Guide: https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site
